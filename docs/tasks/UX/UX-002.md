## Data model

URL query state, TanStack keys include tenant/profile/epoch/publication; no token in localStorage.

## API / interfaces

Semantic request hooks and common response/status rendering.

## Security and tenant isolation

Frontend visibility is convenience only; API/database enforce permissions. Scope-dependent query keys and forms clear on tenant switch/logout. Autocomplete, totals and exported links follow the same access policy.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Read views pin dataset version and query state; mutation forms use idempotency keys and revisions. Prevent double-submit while preserving safe retry after network failure.

## Failure scenarios

Old request resolves after switch; stale browser cache; unauthorized autocomplete; inconsistent currency.

## Observability

Emit task/component, request/run/batch identifier, outcome, duration and a safe error class. Correlate tenant identifiers in protected logs, not unbounded public metric labels. Exclude credentials, full SQL and raw customer payloads. Record counts/checksums or configuration versions appropriate to this task; alert on repeated failures through the shared platform monitoring contract.
