## Data model

Destination version/secret ref/type/verification/status; payload schema and delivery receipt reference.

## API / interfaces

Destination create/test/rotate/pause; adapters expose send(event_id,payload) with bounded timeouts.

## Security and tenant isolation

Monitor scopes and destinations are tenant-owned and bounded by creator permissions; background workers reauthorize before evaluation/delivery. Webhook destinations are untrusted network inputs.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Budget/monitor definitions use revisions; evaluation keys and incident fingerprints deduplicate retries. Outbox delivery is logically idempotent but external ambiguous acknowledgments may duplicate messages and must be observable.

## Failure scenarios

Provider API change; Teams workflow owner removed; SES sandbox; Slack channel revoked; DNS rebinding; callback timeout.

## Observability

Emit task/component, request/run/batch identifier, outcome, duration and a safe error class. Correlate tenant identifiers in protected logs, not unbounded public metric labels. Exclude credentials, full SQL and raw customer payloads. Record counts/checksums or configuration versions appropriate to this task; alert on repeated failures through the shared platform monitoring contract.
