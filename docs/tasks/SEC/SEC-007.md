## Detailed implementation steps

### Micro-task 1

Implement AST-based supported-dialect sanitization; retain only approved dbt/PBI identifiers from structured comments/tags and apply length/type limits.

### Micro-task 2

On parse failure or unsupported syntax set SQL null and privacy_mode_effective METADATA_ONLY; strip sensitive text from exception chains and logs.

### Micro-task 3

Test quoted secrets, JSON literals, comments, COPY credentials, malformed SQL, multi-statements and adversarial Unicode across Arrow/log/report paths.

### Micro-task 4 — Prove and checkpoint

Run the validation below, record expected versus observed results and environment versions, update operational documentation, then checkpoint the task index with the exact next action. Do not mark DONE while a required live gate is unexecuted.
