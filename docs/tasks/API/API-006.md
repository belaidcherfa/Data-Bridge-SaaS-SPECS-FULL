## Data model

Machine client mapping to tenant/scopes/entitlements/revocation; credential secret is Cognito-managed/rotated and neverlogged.

## API / interfaces

Versioned /v1 API; per-client/tenant limits; safe error taxonomy and request correlation.

## Security and tenant isolation

Validate current membership, entitlement and query dimensions before cache/query planning. Principal/profile comes from server mapping; cursors/jobs/explain references are tenant- and scope-bound.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Reads pin publication; POST job/export writes use request hash+idempotency key and durable outbox. Cursor replay is safe within expiry; cancellation and completion compare fencing/revision.

## Failure scenarios

Client secret exposure; grant escalation; breaking API change; quota bypass through different endpoint.
