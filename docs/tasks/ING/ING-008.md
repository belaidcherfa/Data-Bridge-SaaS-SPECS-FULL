## Data model

Journal/raw/published interval sets and monotonic fence; event rows use key+authoritative revision, partition snapshots use selected complete version.

## API / interfaces

compare_and_advance(expected_revision,accepted_intervals); no cross-store transaction assumption.

## Security and tenant isolation

Extractors receive one account identity and prefix; sanitize before serialization; reject file/prefix/manifest identity mismatch. RAW and quarantine are not product-readable.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Immutable attempts plus stable logical window IDs, fenced leases, acceptance gates, deterministic keys and contiguous checkpoints provide idempotent business results over at-least-once transport.
