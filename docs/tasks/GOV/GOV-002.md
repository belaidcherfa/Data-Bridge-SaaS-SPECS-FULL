## Detailed implementation steps

### Micro-task 1

Build seasonal-naive and robust-trend baselines with fixed random seed where applicable; mask missing days rather than filling with zero.

### Micro-task 2

Use rolling-origin backtests, leakage checks and minimum history policy; select simplest eligible model and version all parameters.

### Micro-task 3

Test constant10/day fixture, weekly seasonality, abrupt growth, zero activity, refunds and missing source periods.

### Micro-task 4 — Prove and checkpoint

Run the validation below, record expected versus observed results and environment versions, update operational documentation, then checkpoint the task index with the exact next action. Do not mark DONE while a required live gate is unexecuted.
