## Detailed implementation steps

### Micro-task 1

Build explicit bound queries and set UTC/statement timeouts/query tags containing safe component/run IDs.

### Micro-task 2

Stream Arrow batches through transport validation and sanitizer; bound prefetch/concurrency and bisect oversized windows without losing boundaries.

### Micro-task 3

Kill process mid-fetch, expire credentials, cancel job and inject a giant row; record query ID for safe cancellation/recovery.

### Micro-task 4 — Prove and checkpoint

Run the validation below, record expected versus observed results and environment versions, update operational documentation, then checkpoint the task index with the exact next action. Do not mark DONE while a required live gate is unexecuted.
