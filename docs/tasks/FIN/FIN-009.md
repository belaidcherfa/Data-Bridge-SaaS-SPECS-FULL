GET /v1/reconciliation; POST /v1/reconciliation/runs; import approved statement with provenance.

## Security and tenant isolation

Financial reads honor tenant/account/group profiles; prices and close actions require FinOps permission. Source files and full query text are separately authorized. Never expose another account through org-level residuals.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Every charge/reference/version has a deterministic key; authoritative replacement is scope/version controlled. Closed artifacts are immutable; retries cannot create duplicate charge or adjustment entries.

## Failure scenarios

Tolerance hides material loss; invoice parse ambiguity; dropped adjustment; stale reference; detail sums compared to mismatched scope.

## Observability

Emit task/component, request/run/batch identifier, outcome, duration and a safe error class. Correlate tenant identifiers in protected logs, not unbounded public metric labels. Exclude credentials, full SQL and raw customer payloads. Record counts/checksums or configuration versions appropriate to this task; alert on repeated failures through the shared platform monitoring contract.
