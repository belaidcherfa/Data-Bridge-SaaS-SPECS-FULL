## Detailed implementation steps

### Micro-task 1

Normalize complete billing-day and rate-day snapshots with all billing dimensions; preserve signed amounts and balances.

### Micro-task 2

Implement unique effective-rate selection and fallback to approved tenant rate with estimate label; reject overlapping ambiguous rates.

### Micro-task 3

Test rate change midmonth, reseller no-access, organization fee without account and USD/EUR conversion with explicit FX version.

### Micro-task 4 — Prove and checkpoint

Run the validation below, record expected versus observed results and environment versions, update operational documentation, then checkpoint the task index with the exact next action. Do not mark DONE while a required live gate is unexecuted.

## Data model

Versioned billing snapshot/rate key with contract/region/edition/service/billing/rating/currency/adjustment; approved manual rate provenance.

## API / interfaces

POST /v1/pricing/import and preview; dbt pricing join returns unique rate or UNKNOWN/AMBIGUOUS.

## Security and tenant isolation

Financial reads honor tenant/account/group profiles; prices and close actions require FinOps permission. Source files and full query text are separately authorized. Never expose another account through org-level residuals.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Every charge/reference/version has a deterministic key; authoritative replacement is scope/version controlled. Closed artifacts are immutable; retries cannot create duplicate charge or adjustment entries.

## Failure scenarios

Date-only join; contract overlap; source correction removes row; currency mismatch; unapproved rate import.
