## Data model

## API / interfaces

POST /v1/settings/sso/test; publish; disable with protected owner recovery.

## Security and tenant isolation

Authorization derives from verified identity plus current membership; never trust tenant/profile from raw input. Test foreign tenant and narrower same-tenant scope separately.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Auth callbacks use one-time state/nonce and PKCE verifier; invitation/revocation writes are transactionally idempotent. Permission epoch is monotonic; audit duplicates deduplicate by event_id.

## Failure scenarios

Expired signing certificate; IdP outage; owner lockout; forged domain; inconsistent NameID.
