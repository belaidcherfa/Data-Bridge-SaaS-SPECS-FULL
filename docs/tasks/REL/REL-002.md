## Security and tenant isolation

Deployment and emergency roles are separate from runtime; production access is short-lived, audited and environment gated. Release evidence contains no customer secrets.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Promote by immutable digest; migration steps are resumable and version guarded; one release lock and worker fencing protect concurrent deployments.
