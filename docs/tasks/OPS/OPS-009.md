## Detailed implementation steps

### Micro-task 1

Collect actual provider cost sources and reconcile control totals; allocate shared costs by declared drivers plus unallocated residual.

### Micro-task 2

Compute per-tenant/service/unit COGS and margin with currency/rate/provenance, keeping customer and Bridge expenses separate.

### Micro-task 3

Test1000 revenue/300 COGS gives70%, zero revenue null, shared unallocated cost and delayed provider billing.

### Micro-task 4 — Prove and checkpoint

Run the validation below, record expected versus observed results and environment versions, update operational documentation, then checkpoint the task index with the exact next action. Do not mark DONE while a required live gate is unexecuted.
