## Data model

Definition/layout/filter/template revision; component metric/dimension bindings and required capabilities.

## API / interfaces

CRUD /v1/reports; validate/preview request returns missing capabilities and scope errors.

## Security and tenant isolation

Report ownership, recipients, jobs and object keys are tenant scoped. Rendering is sandboxed, scoped data is handed in explicitly, and every download rechecks current permissions.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Definition revisions and occurrence keys deduplicate jobs; files are immutable by job/version; retry renders to a new attempt key then atomically accepts one manifest.

## Failure scenarios

Broken metric reference; missing optional module; malicious label; currency mixing; owner revoked.

## Observability

Emit task/component, request/run/batch identifier, outcome, duration and a safe error class. Correlate tenant identifiers in protected logs, not unbounded public metric labels. Exclude credentials, full SQL and raw customer payloads. Record counts/checksums or configuration versions appropriate to this task; alert on repeated failures through the shared platform monitoring contract.
