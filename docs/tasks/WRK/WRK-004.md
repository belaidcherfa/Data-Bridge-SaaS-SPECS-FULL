## Data model

Execution graph edges from verified native IDs; workload families tasks/procedures/dynamic tables/apps/SPCS/Cortex/custom/ad hoc.

## API / interfaces

Graph endpoint returns bounded authorized nodes/edges with evidence confidence and cost inclusion flags.

## Security and tenant isolation

Workload tags/comments are untrusted data; parse allowlisted structures and sanitize before central storage. Every hierarchy join carries tenant/account and current access scope.

For this task, test a foreign tenant identifier and an invalid or revoked scope at every input boundary it introduces. Internal infrastructure tasks instead prove environment/principal isolation and absence of public access. Test artifacts use synthetic tenant A/B data only.

## Idempotency / retries

Classifier output is keyed by query+parser version+input revision; reruns replace selected version. Hierarchy aggregates use distinct charge/query links to avoid double attribution.

## Failure scenarios

Cycle; missing root; task instance reused; query ID collision; app grouping overlap.

## Observability

Emit task/component, request/run/batch identifier, outcome, duration and a safe error class. Correlate tenant identifiers in protected logs, not unbounded public metric labels. Exclude credentials, full SQL and raw customer payloads. Record counts/checksums or configuration versions appropriate to this task; alert on repeated failures through the shared platform monitoring contract.
